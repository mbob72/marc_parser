## Что представляет собой проект

MARC Parser преобразует поток записей MARC 21 / ISO 2709 в JSON. Одно и то же
ядро используется двумя способами:

- CLI конвертирует локальный файл и подходит для одиночного запуска или
  standalone-бинарника;
- асинхронный сервис принимает файл по HTTP, ставит задание в RabbitMQ и
  выполняет его worker-процессом, сохраняя данные в MinIO и состояние в
  PostgreSQL.

Главный архитектурный принцип — потоковая обработка. Файл не загружается
целиком в память: splitter выделяет одну MARC-запись, parser строит модель,
validator собирает нарушения, а serializer сразу отдаёт JSON дальше по потоку.

## Границы текущей реализации

- входной формат — MARC 21 / ISO 2709;
- выход — JSON-объект для одной записи, JSON-массив для нескольких и `[]` для
  пустого файла;
- кодировка содержимого задаётся пользователем и проверяется через
  `TextDecoder`;
- API не содержит аутентификацию и предназначен для работы за доверенным
  сетевым периметром;
- миграционного инструмента пока нет: таблица заданий создаётся при старте;
- повторные попытки выполняются немедленно, без задержки и backoff.
