### Правила валидации MARC записи

#### Общие правила

**RS‑G3**
Общая длина записи не может превышать 99 999 символов (ограничение ISO 2709).

**DR‑E2**
Тег (код поля) - состоит из трёх ASCII символов, идентифицирует связанное поле. Может быть цифровым или буквенным (латиница, прописные или строчные, но не смешанно).

**VF‑G3**
Длина каждого поля не может превышать 9 999 символов.


#### Leader

<a id="ld-02"></a>
**LD‑02**

- Позиции 00-04 (Record length): 5-символьное число, выровненное по
  правому краю с ведущими нулями, указывающее общую длину всей записи.
- Позиция 18 (Descriptive cataloging form): профиль РГБ не допускает коды
  `c` и `n`.
- Позиция 19 (Multipart resource record level): профиль РГБ не допускает
  коды `a`, `b` и `c`.


#### Поля данных

**VF‑G5**
Код подполя: односимвольный код, используемый для идентификации отдельных элементов данных в переменном поле. Может быть ASCII строчной буквой или цифрой.

**DF‑G3**
Каждое поле данных содержит как минимум один код подполя.

**DF‑G2**
Каждое поле данных содержит два индикатора (по одному символу каждый) в начале поля.

**IN‑G3**
Индикаторы могут быть ASCII строчными буквами, цифрами или пробелом ( # ).

**SF‑G4**
Идентификатор элемента данных (код подполя) может быть ASCII строчной буквой или цифрой.
