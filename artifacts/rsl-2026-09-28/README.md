# Новые архивы РГБ, 28.09.2026

Источник: https://mrsadman.ru/ac34d2e7ff814daf/, публикация 26.09.2026.
Проверяются все семь баз, включая rsl02. Старые результаты сохранены.

[Отчёт](../../docs/RSL-validation-2026-09-28.md) обновляется после каждой завершённой базы. Пока готовы не все базы, отчёт помечен как предварительный.

- `run-manifest.json` — состояние обработки, источник и SHA-256 кода и архивов.
- `archive-verification.json` — отдельная проверка размера, gzip CRC и SHA-256 архивов.
- `*.errors-only.summary.json` — статистика полного прохода отдельного DAT и его SHA-256.
- `*.errors-only.errors.ndjson` — все ошибки с ID и смещениями записей.
- `by-type/*.tsv` — полные реестры по типам ошибок.
- `records/` — примеры в исходных байтах и читаемом текстовом виде.
- `tests.log` — 96 тестов проекта, все пройдены.

Режим `errors-only`: разбор и валидация без сериализации MARC-JSON. Удалённые DEL-записи пропускаются до валидации. После ошибки отдельной записи аудит продолжается; ошибка границ контейнера делает проход неполным.

Индексы и смещения считаются с нуля. `recordNumber` и `sourceFieldNumber` — с единицы.
