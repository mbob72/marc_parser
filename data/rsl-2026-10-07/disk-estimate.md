Источник: https://mrsadman.ru/ac34d2e7ff814daf/ (проверен 11 октября 2026).
Это выгрузки **Z00**, документы для отдельного проекта `marc_parser`, а не Z103 для парсера связей.

| Файл | Архив, байт | DAT, байт | Архив, ГиБ | DAT, ГиБ |
| --- | ---: | ---: | ---: | ---: |
| rsl01_z00.dat | 3786066397 | 22994648798 | 3,53 | 21,42 |
| rsl03_z00.dat | 446009910 | 2323394333 | 0,42 | 2,16 |
| Всего | 4232076307 | 25318043131 | 3,94 | 23,58 |

Размеры DAT прочитаны из заголовков tar по HTTP-диапазону, без распаковки файлов на диск.

rsl01 уже находился на Mac по пути `/Users/macm1/Desktop/dev/rgb/rsl01_z00.dat.tar.gz`.
В этом каталоге создана символическая ссылка на него, без второй копии. Размер архива,
первые и последние 128 КиБ совпадают с файлом на сервере; выполнена полная проверка gzip.
Сервер не публикует SHA-256, поэтому полное побайтовое совпадение с удалённым файлом не проверено.
Локальные контрольные суммы сохранены в файлах `rsl01.sha256` и `rsl03.sha256`.

## Рекомендуемый режим

В отдельном репозитории `/Users/macm1/Desktop/marc_parser` есть
`scripts/audit-rsl.ts`, режим `errors-only`: проверяет все записи,
сохраняет NDJSON ошибок и JSON со статистикой, без полного JSON документов.
Скрипт читает распакованный DAT. Небольшое число ошибок уменьшает отчёт,
но не требуемое место для исходного DAT.

При ожидаемых нескольких десятках ошибок резервируем 100 МиБ на отчёты
(это запас, а не измеренный размер результата) и ещё 5 ГиБ свободного места.

- Последовательная обработка: после скачивания архивов нужно **27 ГиБ свободно**.
  Распаковать rsl01, выполнить аудит и сформировать отчёт, удалить только временный DAT;
  затем повторить для rsl03. Максимальный DAT занимает 21,42 ГиБ.
- Одновременное хранение обоих DAT: после скачивания нужно **29 ГиБ свободно**.
- На пустом диске вместе с архивами: около **31 ГиБ** для последовательной
  обработки или **33 ГиБ** для хранения обоих DAT.

Пример запуска из репозитория marc_parser (выходной каталог должен быть новым):

```sh
node --import tsx scripts/audit-rsl.ts /path/to/rsl01_z00.dat /path/to/report-rsl01 errors-only https://mrsadman.ru/ac34d2e7ff814daf/
node --import tsx scripts/audit-rsl.ts /path/to/rsl03_z00.dat /path/to/report-rsl03 errors-only https://mrsadman.ru/ac34d2e7ff814daf/
```

Оценка относится к аудиту и отчёту об ошибках. Полная конвертация в JSON или загрузка
в БД потребует дополнительного места и сюда не включена. Потоковое чтение прямо
из tar.gz позволило бы обойтись без DAT на диске, но существующему скрипту для этого
нужна отдельная доработка. В рамках этой задачи исходники проектов не изменялись,
распаковка и аудит не запускались.

После загрузки и удаления временных частей на Mac свободно **30.10 ГиБ**.
Для последовательной обработки нужно освободить дополнительно **0 ГиБ**,
для хранения обоих DAT — **0 ГиБ**. Свободное место изменилось во время загрузки;
перед запуском нужно проверить его повторно.

Оба архива прошли полную проверку целостности gzip; rsl03 скачан полностью.
