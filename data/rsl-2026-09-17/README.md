# Выгрузки РГБ от 17 сентября 2026

Источник: https://mrsadman.ru/ac34d2e7ff814dac/

Библиографические базы: rsl01, rsl02, rsl03, rsl06, rsl07.
Нормативные базы: rsl10, rsl11.

В Git LFS сохраняются оригинальные `archives/*.tar.gz`, кроме rsl01:
он сохраняется побайтно в частях `rsl01_z00.tar.gz.part-*` по 1 000 000 000
байт. Части обходят лимит размера отдельного объекта GitHub LFS.
Распакованные `raw/` и собранный архив rsl01 исключены из Git.
Это обратимое хранение исходников без повторного сжатия или изменения данных.
Старая выгрузка `fixture/rsl06_z00.dat` не заменяется.

Восстановление после `git lfs pull`:

```bash
cat data/rsl-2026-09-17/archives/rsl01_z00.tar.gz.part-* > data/rsl-2026-09-17/archives/rsl01_z00.tar.gz
mkdir -p data/rsl-2026-09-17/raw
for archive in data/rsl-2026-09-17/archives/*.tar.gz; do
  tar -xzf "$archive" -C data/rsl-2026-09-17/raw
done
```

Контрольные суммы находятся в `artifacts/rsl-2026-09-17/*sha256.txt`.
Проверка запускается из корня репозитория через `shasum -a 256 -c <файл>`.

## Коммит и push

Дождаться завершения всех семи диагностических отчётов и формирования частей
rsl01. Проверить отсутствие незавершённых загрузок и итоговый анализ.
Затем добавить `.gitattributes`, `.gitignore`, `scripts/audit-rsl.ts`,
`scripts/run-rsl-audit.sh`, эту директорию, артефакты и страницу анализа.
`git lfs ls-files` должен показывать архивы/части, а не распакованные новые DAT.
Обычный `git push` использует pre-push hook LFS для отправки объектов.
В этой сессии владелец разрешил агенту выполнить коммиты и push.

## Освобождение диска после push

Не удалять файлы до проверки удалённого коммита и доступности каждого LFS-объекта
с ожидаемым SHA-256. Наличие Git-коммита само по себе не доказывает загрузку LFS.
После проверки распакованные копии и собранный rsl01 можно удалить.
Архивы/части в рабочем дереве следует заменить LFS pointer-файлами из индекса,
а не коммитить их удаление. Локальный кэш `.git/lfs/objects` очищается отдельно
только после проверки удалённых копий; обычный `git lfs prune` может сохранить
объекты текущего HEAD. Очистка выполнена 18 сентября 2026 после проверки удалённого коммита,
доступности всех 11 LFS-объектов и SHA-256 локальных исходников. Удалены
семь распакованных DAT, собранный архив rsl01 и локальные копии десяти
архивов/частей (включая их кэш LFS). В рабочем дереве оставлены исходные
LFS-указатели; отчёты ошибок сохранены. Подробности: [local-cleanup.json](../../artifacts/rsl-2026-09-17/local-cleanup.json).

Для повторного анализа сначала восстановите архивы:

```bash
git lfs pull --include="data/rsl-2026-09-17/archives/**"
```

Затем выполните сборку и распаковку из раздела выше.
