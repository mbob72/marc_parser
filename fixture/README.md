## Проверка

Для каждой записи были проверены:

- пятибайтовая объявленная длина;
- наличие полной записи в файле;
- завершающий байт записи `0x1D`;
- разбор текущим `Iso2709MarcParser`;
- правила текущего `MarcRecordValidator`.

Оба файла прочитаны до конца без структурных ошибок и ошибок валидации.
